## Проектыа

### Measurement Microservice
Сервис хранения мерок: вход по номеру телефона (JWT), публичные ссылки на мерки, админ-панель.
`FastAPI` · `PostgreSQL` · `SQLAlchemy` · `Alembic` · `Docker`

- 12 эндпоинтов, 13 тестов на pytest + pytest-asyncio
- 4 миграции Alembic, 55 коммитов — июнь–октябрь 2026

### Сайт аренды одежды — дипломный проект
Backend маркетплейса: каталог, модерация объявлений, поиск с фильтрами, отзывы.
`Django` · `PostgreSQL` · `Docker` · `pytest-django` · `ruff`

- 24 теста: авторизация, объявления, поиск, модерация, отзывы
- Кастомная модель пользователя, data-миграция с seed-данными — октябрь–ноябрь 2026
- [Код](https://github.com/WayHacker/Python_Site_FinalProject_Zernov)
